# הקמת וואטסאפ אוטומטי (ManyChat) — מדריך חד-פעמי להילה

מסמך זה מסביר, צעד אחר צעד, איך מחברים את האתר ל-ManyChat כדי שהודעות וואטסאפ
(אישור תור, תזכורת, בקשת ביקורת ועוד) יישלחו **אוטומטית**.

עד שההקמה תושלם — שום דבר לא נשבר: בממשק הניהול יש כפתורי וואטסאפ ידניים
(בעמוד ההזמנות ובעמוד הגיפט קארדים) שפותחים הודעה מוכנה מראש, והם ימשיכו לעבוד
גם אחרי ההקמה, כגיבוי קבוע.

> **חשוב — לעשות ביום הראשון:** את שש התבניות שבהמשך המסמך צריך להגיש לאישור
> של Meta (זה קורה מתוך ManyChat). האישור יכול לקחת מכמה דקות ועד יום-יומיים,
> ובלי תבנית מאושרת אי אפשר לשלוח שום הודעה אוטומטית. לכן: קודם כל מגישים את
> התבניות, ורק אחר כך ממשיכים בשאר ההגדרות.

---

## שלב 1 — צ'קליסט הקמה חד-פעמי

1. **חשבון ManyChat + חיבור וואטסאפ**
   פותחים חשבון ב-manychat.com ומחברים אליו את מספר הוואטסאפ העסקי
   (ערוץ WhatsApp). עוקבים אחרי האשף של ManyChat עד שהערוץ מסומן כמחובר.

2. **API Token**
   ב-ManyChat: Settings → API → יצירת Token.
   את ה-Token מעתיקים ושומרים — הוא יוזן ב-Vercel בתור `MANYCHAT_API_TOKEN`
   (ראי שלב 4). הטוקן סודי — לא לשלוח אותו בהודעות ולא לשמור אותו במסמכים.

3. **שדה מותאם `wa_phone` + חוק (Rule) שממלא אותו**
   - Settings → Fields → יצירת Custom Field חדש בשם **`wa_phone`** מסוג Text.
   - Automation → Rules → New Rule:
     - טריגר: מנוי חדש הצטרף (New Subscriber / Opted in to WhatsApp).
     - פעולה: Set Custom Field → `wa_phone` = שדה המערכת **wa_id**.
   - בלי זה המערכת לא תצליח למצוא לקוחות קיימים לפי מספר טלפון — זה שדה חובה.

4. **הרשאת יצירת מנויים לפי טלפון (phone import)**
   כדי שהאתר יוכל לצרף לקוח חדש לפי מספר הטלפון שלו, חשבון ה-ManyChat צריך
   הרשאת "יצירת מנוי לפי מספר טלפון". זו הגדרת חשבון (לא קוד) — אם קבלת
   שגיאת הרשאה, פני לתמיכה של ManyChat ובקשי לאפשר phone import לחשבון.

5. **שדות מותאמים לפרסונליזציה** (Settings → Fields, כולם מסוג Text):

   | שם השדה | מה יופיע בו |
   |---|---|
   | `booking_service` | שם הטיפול (למשל "עיסוי תאילנדי") |
   | `booking_datetime` | תאריך ושעה של התור |
   | `review_link` | קישור לכתיבת ביקורת בגוגל |
   | `cancel_link` | קישור לביטול התור |
   | `card_url` | קישור לצפייה בגיפט קארד |
   | `wa_phone` | (כבר נוצר בסעיף 3) |

   **שם פרטי לא צריך שדה** — משתמשים בשדה המערכת First Name של ManyChat.

## שלב 2 — שש תבניות ההודעה (להגשה ל-Meta)

לכל הודעה יוצרים ב-ManyChat **Flow** אחד שבתוכו הודעת WhatsApp Template אחת.
בכל התבניות בוחרים **קטגוריה: Utility** (עדכון תפעולי ללקוח קיים — לא שיווק).
גם תבנית בקשת הביקורת היא Utility: זו הודעת המשך-שירות (follow-up) על טיפול
שהלקוח הזמין וקיבל.

בתוך כל תבנית, המספרים `{{1}}`, `{{2}}`... הם משתנים — אחרי שהתבנית מאושרת,
ממפים כל משתנה לשדה המתאים (בטבלת המיפוי שמתחת לכל תבנית).

### תבנית 1 — הבקשה התקבלה (`received`)

```
היי {{1}} 🙏
הבקשה שלך לתור ל{{2}} ב-{{3}} התקבלה וממתינה לאישור. נעדכן אותך בהקדם!
Halo Yoga & Massage
```

| משתנה | שדה |
|---|---|
| {{1}} | First Name (שדה מערכת) |
| {{2}} | `booking_service` |
| {{3}} | `booking_datetime` |

## שלב 3 — העתקת מזהי ה-Flow (flow_ns)

לכל אחד מששת ה-Flows יש מזהה (נקרא ns — מחרוזת שמתחילה ב-`content...`).
מוצאים אותו בהגדרות ה-Flow או בכתובת הדפדפן כשה-Flow פתוח.

כל מזהה נכנס למשתנה סביבה ב-Vercel:

| Flow | משתנה סביבה ב-Vercel |
|---|---|
| הבקשה התקבלה | `MANYCHAT_FLOW_RECEIVED` |
| התור אושר | `MANYCHAT_FLOW_APPROVED` |
| התור נדחה / בוטל | `MANYCHAT_FLOW_REJECTED` |
| בקשת ביקורת | `MANYCHAT_FLOW_REVIEW` |
| תזכורת יום לפני | `MANYCHAT_FLOW_REMINDER` |
| גיפט קארד אושר | `MANYCHAT_FLOW_GIFT_APPROVED` |

## שלב 4 — הזנת המשתנים ב-Vercel

ב-Vercel: Project → Settings → Environment Variables → מוסיפים:

- `MANYCHAT_API_TOKEN` — הטוקן משלב 1.
- ששת משתני ה-`MANYCHAT_FLOW_*` מהטבלה שלמעלה.

אחרי הוספה — Redeploy לאתר כדי שהמשתנים ייכנסו לתוקף.

**אין חובה להזין הכל בבת אחת:** משתנה שחסר פשוט מכבה את ההודעה המתאימה
(המערכת מדלגת בשקט), וכפתורי הוואטסאפ הידניים ממשיכים לעבוד תמיד.

## מה קורה אחרי ההקמה

- לקוח שקובע תור מקבל אוטומטית "הבקשה התקבלה"; כשאת מאשרת — "התור אושר";
  כשאת דוחה או מבטלת — הודעת הדחייה.
- פעם ביום (בשעות הערב) נשלחות תזכורות ליום המחרת ובקשות ביקורת על טיפולים
  שהסתיימו (בקשת ביקורת נשלחת רק אחרי שהוגדר "קישור ביקורת בגוגל"
  בעמוד "תוכן האתר").
- אישור גיפט קארד שולח לרוכש/ת את הקישור לכרטיס.
- כל הודעה נשלחת פעם אחת בלבד לכל תור — אין כפילויות.
